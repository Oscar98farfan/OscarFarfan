DataLearning: plataforma para practicar ingeniería de datos

Una plataforma para practicar lo que usa un analista o ingeniero de datos, de lo básico a lo avanzado, desde el celular o el PC y sin conexión. El reto técnico fue ejecutar SQL, Python y Git reales dentro del navegador, sin ningún servidor.

El problema

Las plataformas de práctica suelen pedir internet, una cuenta o instalar herramientas, y casi ninguna se usa bien desde el celular. Además, muchas corrigen comparando texto: si escribes una consulta correcta pero distinta a la solución, te la marcan mal.

Cómo lo resolví

  • SQL real: SQLite compilado a WebAssembly. Tu consulta se ejecuta y se compara su resultado con el de la solución, así que cuenta como correcta aunque esté escrita de otra forma.
  • Python y pandas reales con Pyodide, incluido un laboratorio con 24 ejemplos: POO, limpieza de datos, merge, groupby y series de tiempo.
  • Simulador de Git propio: merge de 3 vías, fast-forward, conflictos, rebase, squash, revert, reset, cherry-pick y stash, con 12 retos. En cada caso explica si la historia se conserva o se reescribe.
  • Laboratorio de IA: simulación de tokens, temperatura, embeddings y RAG paso a paso.
  • Funciona sin internet: es una PWA con service worker que se instala en el celular como una app.
  • Siete temas: Python, Pandas, SQL, Power BI / DAX, Git, arquitectura de datos (Spark y Delta) e IA generativa, en tres niveles.

Calidad

Una batería de pruebas (npm test) ejecuta cada solución: que cada SQL corra sobre los datos, que cada ejemplo de Python funcione en Python real y que cada reto de Git se resuelva. También verifica que el modo sin internet incluya todos los archivos.

Siguientes pasos

Una ruta de aprendizaje con mini proyectos (Bronze → Silver → Gold con un caso de ventas) y login con Supabase para sincronizar el progreso entre dispositivos.
